# 论文拟定标题
**中文：** 基于跨模态注意力与物理约束的 SAR 图像抗配准误差联合去噪与超分辨
**英文：** Misalignment-Robust Joint Despeckling and Super-Resolution for SAR Images via Cross-Modal Attention and Physics-Informed Constraints

## 0. 摘要 (Abstract)
*   **背景：** 合成孔径雷达（SAR）图像具有重要的遥感观测价值，但固有的相干斑噪声和较低的空间分辨率严重限制了其在多源信息融合与地物解译中的应用。利用高质量光学图像作为空间结构先验是提升 SAR 图像质量的有效途径。
*   **痛点：** 现有的光学引导方法通常假设两模态图像**完美像素级配准**，而在实际中，由于 SAR 的侧视几何畸变，微小的配准误差会导致融合结果产生严重的边缘伪影。此外，传统的全变分（TV）或 MSE 损失会平滑掉 SAR 图像中极其重要的孤立强散射目标（如车辆、舰船）。
*   **方法：** 本文提出一种新型跨模态融合网络 MMCANet。通过引入**局部交叉注意力机制（Cross-Attention）**，网络能够在局部感知野内柔性对齐光学结构与 SAR 特征，从而有效克服空间配准误差；同时，设计了结合**SAR 比值图像和自适应平滑的物理约束损失（Physics-Informed Loss）**，在抑制背景噪声的同时完美保留高价值散射点。
*   **结果：** 在 SEN12MS-CR（或本地构建）数据集上的实验表明，该方法在 PSNR、等效视数（ENL）和目标背景比（TBR）等指标上显著优于传统的级联方法（Cascade）和硬拼接（Concat）融合网络，有效避免了融合伪影。

## 1. 引言 (Introduction)
*   **1.1 研究背景：** SAR 图像去噪（Despeckling）与超分辨（SR）往往作为独立的串行任务，这会导致误差累积（去噪丢失高频，超分放大噪声）。因此，**联合去噪与超分（JDSR）**成为当前的研究热点。
*   **1.2 引入光学先验的必要性与困境：**
    *   *优势：* 光学图像具有清晰的边缘和纹理。
    *   *困境一（配准误差）：* 现有的早期融合（Early-fusion, 即通道拼接 Concat）极度依赖配准精度。SAR 的透视收缩和叠掩使得完美配准几乎不可能，强行融合会产生“双重边缘”或“鬼影”。
    *   *困境二（目标抹除）：* 传统深度学习损失（L1/L2）或平滑正则化，未考虑 SAR 乘性斑点噪声特性，容易将高频强散射目标当做噪声抹除。
*   **1.3 本文贡献 (Contributions)：**
    1.  提出 MMCANet，利用交叉注意力实现跨模态的“柔性对齐”，打破了对像素级完美配准的严苛依赖。
    2.  提出一致性门控机制，对交叉注意力输出进行像素级置信度控制，在变化区域自动衰减光学引导，从而缓解“时相幻觉”和错误结构注入。
    3.  提出一种物理驱动的复合损失函数（包含自适应TV与比值图约束），保护 SAR 的强散射后向特性。
    4.  提出了一种易于部署的端到端自监督/弱监督闭环训练范式，为多源遥感下游任务提供了高质量的数据预处理方案。

## 2. 方法 (Methodology)
这是论文的核心主体，详细介绍你代码里的内容。

*   **2.1 网络整体架构 (Overall Architecture of MMCANet)：**
    *   简述双分支结构：光学特征提取分支（如浅层 CNN/残差块）与 SAR 重建主干网络。
    *   描述数据流：输入低清带噪 SAR ($SAR_{LR}$) 和高清光学 ($Opt_{HR}$)，输出高清去噪 SAR ($SAR_{HR\_clean}$)。
*   **2.2 抗配准误差跨模态融合模块 (Misalignment-Robust Cross-Modal Fusion)：**
    *   *数学描述：* 将 SAR 特征作为 Query ($Q$)，光学特征作为 Key ($K$) 和 Value ($V$)。
    *   *机制解释：* 通过计算 $Q$ 和 $K$ 的相关性矩阵，模型可以在局部窗口内自适应地寻找最匹配的光学边缘来增强 SAR 特征，从而从根本上容忍了几何形变和配准偏移。
    *   *一致性门控：* 在注意力输出后增加置信度图 $C \in [0,1]$，可由 attention 熵、最大权重或双向 cycle consistency 估计。将 $C$ 作用于 $V$ 或融合特征，使高置信区域强注入、低置信区域弱注入，避免将旧时相结构错误写入 SAR。
*   **2.3 物理约束损失函数 (Physics-Informed Loss Function) [重点亮点]：**
    *   列出总损失公式：$L = \lambda_1 L_{Rec} + \lambda_2 L_{Ratio} + \lambda_3 L_{Adaptive\_TV}$。
    *   **$L_{Rec}$ (重建损失):** 保证宏观结构相似性（可用 L1 或 SSIM）。
    *   **$L_{Ratio}$ (比值损失):** $Ratio = SAR_{noisy} / SAR_{clean}$。论述在物理上 $Ratio$ 应只包含纯相干斑噪声，以此约束网络不抹除目标。
    *   **$L_{Adaptive\_TV}$ (自适应平滑损失):** 结合光学边缘检测算子和 SAR 变异系数（CV）计算空间权重矩阵 $W$。在平坦区域平滑，在目标处停止平滑。
