# Phase E Task B 全球 Sentinel-1 表示域合成 Pilot 结果与研究决策复核（2026-11-28）

## 决策

**停止本协议下的两项生成式候选。** 候选 A 的均值校正残差 DDIM、候选 B 的矩匹配似然引导 DDIM 均未通过冻结的 development 继续门槛。候选 B 单次 draw 相对最强学习基线 EDSR 的组配对 PSNR 差为 −17.4368 dB，95% bootstrap 区间为 [−18.0755, −16.7937] dB；结构和观测重投影指标也不合格。预登记的两个候选名额已经用完，不在本轮追加第三个候选、不回调引导系数。

这项决定只适用于下述多时相 GT25 伪参考上的固定表示域合成任务，不否定所有 Flow 或 diffusion 方法，也不改变 C2、C3-A/C3-B 的阶段 gate。

## 任务和数据边界

### 候选 A：均值校正中心残差扩散

- 均值校正点估计没有超过 EDSR：ΔPSNR = −0.3476 dB。加入中心残差扩散后，单 draw ΔPSNR = −19.2125 dB，10,000 次来源组 bootstrap 95% CI 为 [−19.7142, −18.7069] dB；四次抽样像素均值仍比 EDSR 低 14.5847 dB。
- 目标中心残差标准差均值为 0.0631，生成残差标准差均值为 0.5081；生成与目标残差的相关系数均值为 0.0017。四次 draw 的像素标准差均值为 0.4003。输出大量堆在表示域两端，低/高饱和比例均值分别为 52.53%/46.27%。
- 继续 gate 为 false。该结果显示候选网络没有学到可用的残差修正；均值之后的扩散样本也没有恢复结构或稳定改善重投影。

### 候选 B：零训练矩匹配似然引导

- 复用候选 A 第 3 轮 EMA checkpoint（SHA-256：`3e7be2b7203c77866c7adc0a205137d74fca232f55fec447975092b84c891dd5`）、同一均值校正器和四个固定 seed，仅在每个 DDIM 反向步加入单位系数的矩匹配似然梯度。
- 单次 draw 比无引导候选 A 高 1.7757 dB PSNR，但相对 EDSR 仍低 17.4368 dB，EPI 为负，重投影 MAE 从无引导的 0.3330 增至 0.4213。四次像素均值 PSNR 为 8.9692 dB，低于候选 A 的 10.0811 dB。
- 四个 draw 的逐图 PSNR 范围约 7.1848–7.2934 dB；跨 draw 每像素标准差均值为 0.1363。输出低端 `≤0.001` 占 8.89%，高端 `≥0.999` 占 91.11%，依旧严重饱和。似然是 Gamma 加权和前两矩的异方差高斯近似，不是精确概率密度或 SAR 物理似然。
- 继续 gate 为 false。单位引导提高了一些单次指标，但没恢复结构，且增加低分辨率观测重投影误差；不按开发集后验调权重。

## 研究结论与边界

**事实：** 两项冻结配置在该表示域合成任务的 70 个 development 组上都未通过预登记 gate；EDSR 是本次比较中最强学习方法。候选 A 训练出的扩散残差方差远大于目标残差方差；候选 B 的单位似然近似引导仍无法抑制饱和和结构失配。

**观察：** 在本 run、本 seed、本数据代理与固定采样器条件下，像素均值比单次 draw 好，但仍远落后 EDSR；似然引导提高单次 PSNR，却恶化重投影误差并让像素均值变差。

**未知：** 这些失败能否迁移到有可靠单景 SAR 观测模型或真实配准多时相 SAR 的任务；其它训练目标、噪声参数化或采样器是否有效；匹配 Optical 是否增益。当前实验不回答这些问题。

**决定：** 停止这两个已冻结候选。保留负结果与所有样本；不追加同协议 seed，不做 hindsight 调参，也不把代理任务的 PSNR 解释为 clean-SAR 恢复或 independent generalization。继续工作转向取得可审计的广域配对数据与新 development 协议；Optical 增量验证仍需单独授权与合格数据协议。
