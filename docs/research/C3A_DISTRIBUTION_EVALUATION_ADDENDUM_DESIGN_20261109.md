# C3-A 多样本分布评价补充设计

> **状态：** 设计稿，未启用。本文不修改已冻结的 C3-A v3，也不授权训练、GPU 推理、模型评价或任何阶段晋级。

## 1. 目的

研究总纲 v1.8 要求将随机恢复方法的单次 draw、像素均值点估计和样本分布分开评价。C3-A v3 当前只逐 draw 计算标量指标并报告逐像素样本标准差，不计算均值图质量、空间分布距离或 draw 相关性。该实现符合冻结协议，但不足以回答新增的分布问题。

本设计提出一个可在训练恢复后另行预登记的补充评价框架。由于现有 development 已重复用于训练与选择，补充结果仍属探索性描述，不用于独立泛化主张或追溯晋级。

## 2. 评价对象与数据边界

对固定身份、固定 LR SAR 和 noisy pseudo-target，分别记录：

1. **单次 draw：** 沿用现行 C3-A v3 的逐 draw 指标和失败统计。
2. **像素均值点估计：** 由集合中的 draw 按固定顺序逐像素求均值，单列为点估计；不并入单 draw 统计。
3. **预测集合：** 评价每个身份的边缘分布与空间依赖，并报告 draw 数、随机种子和依赖结构。

若模型输出为 SAR 表示域中的归一化 `[0,1]` PNG，所有指标只能解释为与 noisy pseudo-target 的表示域一致性；它们不等价于 clean-SAR 恢复质量或物理后验校准。

此设计只考虑 development 描述性评价。不得读取或评价 confirmation/test 影像及其测量值；C1 v2 不提供独立 test。未来如需确认性结论，必须先由用户授权并建立独立、来源组隔离且未参与选择的确认数据流程。

## 3. 候选评价量

### 3.1 逐像素 CRPS：边缘分布

对像素位置 `i`、集合预测 `X_1,…,X_K` 和 noisy pseudo-target `y_i`，计算经验 CRPS：

```text
CRPS_i = mean_k |X_k,i - y_i| - 0.5 * mean_{k,l} |X_k,i - X_l,i|
```

先在每个图像内部对有效像素求均值，再按来源组等权汇总。该量评价像素边缘分布；相同边缘但不同空间结构时可能无法区分。

### 3.2 归一化整图能量分数：联合分布

将图像展平为 `P` 维向量，计算：

```text
ES = mean_k ||X_k - y||_2 / sqrt(P)
     - 0.5 * mean_{k,l} ||X_k - X_l||_2 / sqrt(P)
```

它以整图向量为评价对象，须与逐像素统计并列报告。能量分数在一般条件下具有严格适当性，但多变量预测研究指出，它对部分分量相关失配可能不够敏感；因此须与空间结构评价和已知案例并列检查，不能把“适当”当成对所有错误都有高检出力。参见[Gneiting 与 Raftery (2007)](https://doi.org/10.1198/016214506000001437)及[Scheuerer 与 Hamill (2015)](https://doi.org/10.1175/MWR-D-14-00269.1)。单独变好不能证明 SAR 物理真实性或目标 clean-reference 质量。

### 3.3 邻接变差分数：局部空间依赖

固定水平和垂直相邻像素集合 `E`，逐边比较观测差值与集合预测差值的均值：

```text
VS = mean_(i,j in E) ( |y_i-y_j| - mean_k |X_k,i-X_k,j| )^2
```

当前候选取 `p=1`，在变差评分文献中称为 madogram。边界、归一化、无效像素掩膜、配对集合 `E` 和权重须在运行前固定。变差分数适当但非严格适当，只比较预设配对的幂矩，可能漏掉联合分布中的其他差异；因此须与 CRPS/边缘统计和整图分数合用。它不替代亮点、边缘、ratio 或整体目标一致性评价。参见[Scheuerer 与 Hamill (2015)](https://doi.org/10.1175/MWR-D-14-00269.1)。

2026-11-09 的补充纯 CPU 诊断构造了两个具有相同像素边际和相同 1 像素相关、但远距离相关不同的可分离协方差过程。只算 `h=1` 的变差分数在双向检验中的正确排序比例为 0.490/0.473；对 `h={1,2,4,8}` 四个单尺度分数等权平均后为 0.990/0.857。该证据说明本设计当前的“相邻变差”候选覆盖不了所有空间依赖差异；多距离版本可保留为未来待比较候选。结果只适用于该 logistic-normal 合成核，不确定多距离集合、权重、边界或尺度能否迁移到本地 SAR 输出；不据此修改 C3-A v3、正式协议或指标门槛。见[多距离合成诊断](../../experiments/synthetic_cpu/c3a_spatial_variogram_multiscale_cpu_20261109_v1/report.md)。

后续相关强度敏感性诊断将 ρ 扩展为 0.4、0.6、0.8、0.9，双向真值共 8 个条件中有 7 个达到预登记门槛；ρ=0.4、RBF 真值的正确排序率为 0.600，未达 0.65，尽管平均差区间下界大于零。由此，多尺度候选的区分能力表现出相关强度与真值方向依赖；该敏感性结果进一步限制外推，不支持把现有四距离或等权设置直接用于 SAR。见[相关强度敏感性报告](../../experiments/synthetic_cpu/c3a_spatial_variogram_correlation_sweep_cpu_20261109_v1/report.md)。

另一项轴向错配诊断令横纵 AR(1) 相关值 0.75/0.35 互换。当前逐边平方误差实现的 h=1 和四尺度评分在两种真值方向均达到预登记门槛，说明该构造下评分保留了方向信息；但 h=8 单尺度排序率仅为 0.593。CRPS 和整图能量分数未区分该错配。此结果仅核验平稳可分离各向异性案例，不证明对非平稳结构或真实 SAR 充分，也不支持修改代码或重新加权。见[轴向错配报告](../../experiments/synthetic_cpu/c3a_spatial_variogram_anisotropy_cpu_20261109_v1/report.md)。

### 3.4 质量与安全护栏

预测集合还需逐身份报告逐 draw 的范围/NaN/Inf、饱和比例、目标—背景稳健对比、亮点强度、边缘保持和 ratio 统计。均值图单独计算同类点估计指标，并标记为聚合输出。任何显示拉伸与评价输入分离。

## 4. 已知案例与当前证据

预登记真实模型补充协议前，指标实现至少应能区分以下构造：

- 目标均值处的塌缩点：均值误差可为零，但样本距离和模态支持为零；
- 均值/协方差匹配但分布形状错误的单峰分布；
- 同边缘分布但空间依赖错误的图像集合；
- 一阶邻接统计相同但较远距离相关不同的空间过程；
- 均值正确但方差错误的乘性随机变量。

2026-11-09 的三项纯 CPU 诊断为以上案例提供初步证据：[二维评价量诊断](../../experiments/synthetic_cpu/c3a_distribution_metric_sanity_cpu_20261109_v1/report.md)、[样本数敏感性诊断](../../experiments/synthetic_cpu/c3a_distribution_draw_count_cpu_20261109_v1/report.md)、[图像域空间依赖指标诊断](../../experiments/synthetic_cpu/c3a_image_distribution_metrics_cpu_20261109_v1/report.md)。评分规则依据与适用边界见[一手来源核验](../../experiments/literature_audits/proper_scoring_rules_multisample_eval_20261109_v1/report.md)。这些证据不决定实际模型的 draw 数或指标阈值。

## 5. 运行前必须冻结的项目

补充实验启动前，需另行形成有唯一版本号的完整 protocol，至少明确：

- checkpoint、development 清单、来源组、LR/target 输入及其哈希；
- 每个身份的 draw 数、seed 派生、生成顺序、模型和 checkpoint 绑定；
- 三类评价对象的汇总顺序、掩膜、动态范围、有效像素和指标方向；
- 样本相关性和均值点估计的分析计划，以及不能估计时的标注方式；
- 逐图与逐来源组统计、置信区间/重抽样单位和多重比较处理；
- 输出保存策略、磁盘预算、运行命令、环境和停止/失败条件。

不从二维合成实验直接移植 `N=16` 或 `N=32`。真实 draw 数须结合明确的算力/磁盘预算及已冻结的科学问题确定。以 200 张 `256×256` 的 float32 预测为例，单 draw 约 52.4 MB；16 draws 约 839 MB（十进制），尚未计入 checkpoint、临时文件和其他产物。启动前重新检查分区余量。优先选择可复算且不会覆盖历史结果的唯一目录；是否保存完整预测张量或只保存预登记的充分统计量，应在 protocol 中先决定。

## 6. 当前决定与恢复条件

- 本设计尚未成为 C3-A 的新协议，不修改 v3、模型源码或结果目录。
- 用户已要求暂停训练任务；因此当前不执行模型推理或真实输出评价。
- 用户恢复训练后，先审阅并冻结补充 protocol，再决定是否运行。若 development 结果用于任何选择，仍标为探索性；不得据此宣称独立泛化或修改历史 gate。
- 训练/GPU 恢复之前，继续只做有直接源码、协议或一手元数据证据支撑的 CPU 工作。

## 7. 候选评分量隔离原型（2026-11-09）

候选公式已有独立 NumPy 实现：[scripts/distribution_metrics.py](../../scripts/distribution_metrics.py)。10 项 CPU 定向测试覆盖已知值、精确集合和主要形状/有限值/范围失败条件；另以固定种子随机合成数组和独立向量化公式交叉核对，三项分数最大绝对差为 `2.776e-17`。原型不接入 C3-A v3、不读取项目数据、不运行模型；它只降低未来重新实现公式时的基础软件风险。

2026-11-09 对 `[16,256,256]` 合成集合的单图 CPU 耗时初测：逐像素 CRPS、整图能量、邻接变差的中位数分别为 16.700、7.183、14.568 ms。此数据不包括模型采样或 I/O，不能线性外推整套开发集或 GPU 预算；详见[耗时诊断](../../experiments/synthetic_cpu/c3a_distribution_metric_runtime_cpu_20261109_v1/report.md)。

该实现验证不代表补充评价 protocol 已完成，也不说明三项分数在真实 SAR 表示域中充分。启用前仍须另行冻结指标权重/边集合、缺失像素处理、统计汇总和输出产物，并验证更大输入下的时间与内存需求。
