# Phase D2 Gamma 观测零值支持域审计方案

**状态：执行前固定**  
**日期：2026-11-24**  
**目的：** 在设计表示域 Gamma 似然项前，量化固定 train/development SAR LR 中由退化链非负截断造成的精确零值；不训练模型、不调似然参数、不访问受保护集合。

## 范围

- 只读取冻结 C1 v2 `x2_light` 的 train（1,600 张、92 组）和 development（200 张、19 组）SAR `lr/*.npy`，并只从各自 `files.csv` 读取样本 ID 和来源组。
- 不读取 target、optical、confirmation/test 清单成员、图像、指标或载荷；不改变固定输入。
- LR 值允许大于 1；不做 clamp、重归一化或量化。
- development 已重复用于历史训练/选模。本审计仅作观测模型实现前的描述性统计，不作泛化、模型选择或晋级证据。

## 固定统计量

逐图计算精确零像素数/比例、正值像素数、最小正值；按来源组等权汇总零比例。分别报告全像素池化值、逐图中位数/范围、来源组等权均值及按组 bootstrap 95% 描述区间。`x == 0` 使用 float32 精确相等判断，不设事后阈值。

## 解释边界

当已核验的退化链先对下采样结果执行 `clamp_min(0)`，随后乘以严格正值 Gamma 随机变量，精确 LR 零值对应截断后输入为零（忽略浮点下溢这一数值极限情形）。正值区使用连续 Gamma 密度；零值是截断机制带来的点质量/删失观测，不能直接套用普通正值 Gamma 对数似然，也不能用任意 epsilon 替代而不说明。

本审计只量化这一数值现象，不据此确认传感器噪声、辐射量或真实 SAR 物理模型。
