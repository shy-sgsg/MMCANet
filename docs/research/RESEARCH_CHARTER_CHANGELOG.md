## 3. 对现有研究与未来阶段门槛的影响

### 历史证据与门槛

- 按原样保留所有 B1/B1R/B1F、Phase-1 R/S/T、Phase-A2 和 C2 产物、指标、失败、配置与决策。
- 保持 B1 为 `not_promoted / stop_at_b1`；不得改写为光学有效，也不得改写为 `Joint > Strong Cascade`。
- 不得用已受污染的 `fixed_val_dev2k` 和 B1F inner-dev 进行未来模型选择或独立泛化主张。
- 保持当前 C1 v2 范围狭窄：仅在来源文件夹隔离条件下供 C2 开发使用；不主张地理／采集独立、精细配准或已确认的空间独立性。
- 在设计和选择期间，继续封存 confirmation 与 test 图像／测量结果。D-2026-10-29-005 已将本次总纲审阅文本暴露记录为 `test_set_accessed=true`、`test_set_used=false`；C2 协议标记仍为 `false/false`。

### 后续研究路径

若采纳候选方案，将在受保护指令同步后建立拟议的 C1–C6 后续顺序。但这不会使 C2 可立即运行：v2 筛查仍缺少端到端运行器和剩余验收证据，也不会授权新运行或访问 confirmation／test。每个阶段仍须分别完成准备检查、冻结协议、资源预检和决策记录。

当前 B2/B3 错配路线继续保持门控，直到未来获批的政策明确厘清该历史门槛与前瞻 C5 路径的关系。仅批准研究主题不能追溯性地让 B1 通过，也不能豁免项目的数据、测试或公平性约束。

### 论文影响

主题提案会将未来论文叙事从“先介绍 MMCANet 架构”转向以问题为先的顺序：数据与观测模型 → 光学价值 → 生成式方法价值 → 观测一致性 → 仅在证据需要时研究可靠性／回退机制。该提案不授权编辑归档论文、不引入与测试集有关的历史文字、不在缺乏证据时保留 “physics-consistent” 表述，也不允许把旧固定集合数值作为当前结果。只有方法专属门槛和完整的主张—证据链通过后，才建立投稿稿件。

## 9. 条件性物理一致性标题的数据现状边界 — 2026-10-29
