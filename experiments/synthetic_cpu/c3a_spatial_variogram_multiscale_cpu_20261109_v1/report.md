# 单尺度与多尺度变差分数空间依赖诊断

**实验编号：** `c3a_spatial_variogram_multiscale_cpu_20261109_v1`  
**运行日期：** 2026-11-09  
**类型：** 纯合成 NumPy CPU 方法诊断，不是 SAR 影像实验或模型结果。  
**状态：** 按[预登记协议](protocol.md)完成。

## 问题与方法

检验当前只使用 1 像素邻接的变差分数，能否区分边际分布和一阶空间相关相同、较远距离依赖不同的两个过程；并比较四个距离 `h={1,2,4,8}` 等权平均的多尺度变差分数。使用 24×24 可分离高斯场，经 sigmoid 映射到 `[0,1]`；比较 `AR(1)` 与 RBF 协方差。两者的像素边际分布相同，水平/垂直相邻相关均为 0.8。分别以两种协方差为真值，各评 300 个独立目标；每种候选预测集合含 16 draws。评分和重抽样规则、seed 与阈值见协议。

所有平均差均定义为“错误预测分数减正确预测分数”，正值表示正确预测在平均上得分较低。逐重复排序比例表示错误模型与正确模型对同一目标相比，正确模型得分更低的比例。平均差 95% 区间采用 2,000 次、按目标重复重抽样的 percentile bootstrap。

## 结果

### AR(1) 为真值

| 评分量 | 平均配对分差 | 95% 区间 | 正确模型排序比例 |
|---|---:|---:|---:|
| 逐像素 CRPS | -0.00005379 | [-0.00039797, 0.00026127] | 0.533 |
| 整图能量分数 | 0.00013040 | [-0.00022403, 0.00047683] | 0.527 |
| 变差分数 `h=1` | -0.00000315 | [-0.00002206, 0.00001580] | 0.490 |
| 变差分数 `h=2` | 0.00209374 | [0.00201138, 0.00217385] | 1.000 |
| 变差分数 `h=4` | 0.00361706 | [0.00345070, 0.00377878] | 0.990 |
| 变差分数 `h=8` | 0.00070567 | [0.00057024, 0.00083692] | 0.723 |
| 四尺度等权平均 | 0.00160333 | [0.00152351, 0.00168156] | 0.990 |

### RBF 为真值

| 评分量 | 平均配对分差 | 95% 区间 | 正确模型排序比例 |
|---|---:|---:|---:|
| 逐像素 CRPS | 0.00009506 | [-0.00019475, 0.00036593] | 0.530 |
| 整图能量分数 | 0.00031139 | [0.00003355, 0.00061630] | 0.540 |
| 变差分数 `h=1` | -0.00000368 | [-0.00002321, 0.00001491] | 0.473 |
| 变差分数 `h=2` | 0.00121879 | [0.00111690, 0.00131845] | 0.923 |
| 变差分数 `h=4` | 0.00227448 | [0.00206459, 0.00248632] | 0.897 |
| 变差分数 `h=8` | 0.00025734 | [0.00012960, 0.00038421] | 0.580 |
| 四尺度等权平均 | 0.00093673 | [0.00083849, 0.00102869] | 0.857 |

预登记的描述性条件达到：四尺度平均在两种真值方向均使正确协方差模型取得更低平均分，且排序比例分别为 0.990 与 0.857（均大于 0.65）。单尺度 `h=1` 的排序比例为 0.490 与 0.473，落在预登记的 0.40–0.60 范围内。逐像素 CRPS 没有区分两种相同边际过程；整图能量分数的逐目标排序比例也接近 0.5，尽管 RBF 真值下平均差区间略高于零。

## 解释与限制

在这个特定协方差对照中，单尺度 `h=1` 只检查具有匹配二像素分布的邻接对，不能识别远距离依赖差异；加入 `h=2` 和 `h=4` 后区分明显。`h=8` 的逐目标区分较弱，说明简单增加距离并不保证每个尺度都更有信息。四尺度均值在该构造中表现较好，但不说明这些距离或等权权重适用于 SAR 图像。

结果只覆盖 24×24 logistic-normal 边际、两种可分离协方差核、K=16、每方向 300 个合成目标和预先固定的四个距离。它不能证明真实 Flow/Diffusion draws 的空间校准、SAR 物理一致性或 noisy pseudo-target 恢复质量，也不验证其他纹理、非平稳场、散射点或噪声模型。不得据此修改 C3-A v3、确定真实模型的评分权重、门槛或 draw 数。若未来另行冻结多样本补充协议，可把多距离变差分数列为待比较候选；必须先用更多已知案例及预先声明的空间距离/权重验证。
