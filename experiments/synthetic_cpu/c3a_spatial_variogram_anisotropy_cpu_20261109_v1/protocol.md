# 方向相关结构错配的变差分数诊断协议

- **版本：** c3a_spatial_variogram_anisotropy_cpu_20261109_v1
- **状态：** 运行前预登记
- **问题：** 当前变差评分对全部水平边与垂直边逐边计算平方误差后再汇总。检验当真实过程的水平/垂直相关强度不同时，轴向交换的错误预测是否仍可被单尺度与多尺度变差分数识别。

## 固定构造

- 图像为 24×24 可分离高斯场，经 sigmoid 映射到 [0,1]。
- 两轴分别采用 AR(1) 协方差；弱相关为 0.35，强相关为 0.75。
- 两个真值方向分别为：横向 0.75/纵向 0.35；横向 0.35/纵向 0.75。两个预测候选为方向正确的协方差和交换横纵相关强度的协方差。
- 每个真值方向生成 300 个独立目标；每个目标 16 个预测 draw。正确/交换预测使用共同高斯创新形成配对比较。
- 评分沿用 [c3a_spatial_variogram_multiscale_cpu_20261109_v1/run.py](../c3a_spatial_variogram_multiscale_cpu_20261109_v1/run.py) 的 CRPS、整图能量分数与变差分数实现；变差距离为 h={1,2,4,8}，多尺度分数为四个距离等权平均。
- 生成 seed：20261112；按目标 bootstrap seed：20261113；每条件 2,000 次重抽样。

## 预先声明的判定

- 对每个真值方向，若多尺度变差分数的错误减正确平均配对分差 95% bootstrap 区间下界大于零，且正确模型逐目标排序比例大于 0.65，则记录该方向达到描述门槛。
- h=1 单独报告，不要求失败；该项用于观察方向错配是否已能被相邻像素统计识别。CRPS 与能量分数作为描述性对照，不设通过阈值。
- 两个真值方向均完整报告，不根据结果选方向、尺度或评分量，不更改现行公式或任意 gate。

## 数据与设备边界

只生成合成矩阵。不得读取项目影像、模型、checkpoint、confirmation/test 载荷或测试测量值。无训练、推理、PyTorch 或 GPU。结果仅描述 24×24 logistic-normal、两个轴向相关值及 K=16；不解释为 SAR 物理测量或真实模型表现。
