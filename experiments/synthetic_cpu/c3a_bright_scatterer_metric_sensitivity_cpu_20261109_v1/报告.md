# 稀疏亮点退化下的多样本全局评分敏感性

## 研究问题与预登记协议

在 64×64 的归一化图像中设置 4 个稀疏亮点，其余像素为均匀背景。对观测和 16 个预测 draw 施加独立乘性 Gamma 随机场，并比较正确预测、亮点压暗、亮点漏检、整体错位 1 像素和额外伪亮点五种条件。每种条件运行 300 次独立重复；同一重复共用观测与预测噪声实现，形成配对比较。

预登记指标为逐像素 CRPS、归一化整图能量分数和一像素邻接变差分数，均为越低越好。报告错误条件减正确条件的配对分差、95% bootstrap 区间及分差为正的重复比例。局部护栏统计亮点均值、精确位置/3×3 邻域检出率、真目标区域外伪亮点率及背景中位数。阈值固定为 0.25。

这是纯合成数学构造。Gamma(shape=16, scale=1/16) 只定义乘性随机变量，不能解释为本地 PNG 的物理噪声或定标视数。

## 结果

乘性噪声抽样均值为 0.999493，理论值为 1；样本方差为 0.062384，理论值为 0.0625。观测裁剪比例为 0；各预测条件平均裁剪比例均不超过 2.55×10⁻⁷。

## 方法判断

- 在本次 64×64、4 个亮点和 16 draws 的构造中，三项全图评分都能区分错误预测与正确预测。漏检、错位及增加伪亮点的分差在 300 次重复中始终为正；压暗条件为 0.893。
- 局部护栏提供了不同的诊断信息：精确检出率将“漏检”和“右移”同样标为未命中，而 3×3 邻域检出率显示右移仍保留了附近亮点；伪亮点率单独识别了额外结构。
- 当前结果没有显示现有评分实现需要修改。局部亮点统计可作为未来补充评价设计的候选护栏，但本实验不启用新评价协议，也不规定阈值或阶段 gate。

上述结论只适用于指定的合成场景和重复范围，不能证明评分量足以处理更大图幅、不同亮点密度、真实 SAR、真实模型预测分布或 clean-reference 恢复质量。

## 执行与产物核验

- 运行脚本先通过 py_compile，再以 CPU 完成 300 次重复、五种条件，共生成 1,500 条逐重复记录；所有评分均为有限值。
- Gamma 样本均值/方差符合预登记容差。协议、脚本、逐重复 CSV 和汇总 JSON 的 SHA-256 与运行清单一致。
- 运行未导入 PyTorch；仅使用 NumPy，没有读取项目图像、模型、checkpoint、confirmation/test 载荷或测试测量值，也没有训练、推理或使用 GPU。
- 产物仅为协议、脚本、标量 CSV、汇总 JSON、运行清单及本报告；没有保存图像张量或大型缓存。
