**协议版本：** v1r1（实现维度一致性修订）。
**状态：** 运行前冻结。
**日期：** 2026-11-09。
**类型：** 纯合成、NumPy CPU 方法诊断；不含训练或项目图像。

原协议明确规定目标维数为 6、观测维数为 3、64 个先验成分。首轮实现错误地用了 5 维、32 个成分；首轮产物保留在 `../posterior_score_calibration_cpu_20261109_v1/` 并标记为无效。v1r1 只修正实现与原协议之间的这一不一致，不改变统计模型、样本数、评价量、预声明判据或停止规则；本协议在有效复跑前冻结。

## 2. 研究问题与已知后验

检验逐维 CRPS 与边际可信区间覆盖率，能否在可精确求解的小型逆问题中，把真实后验预测分布与后验均值塌缩、欠分散及过分散的预测分布区分开。该问题补充评分公式与空间依赖合成诊断，不评价 SAR 模型或 C3-A v3。

- 目标维数 `d=6`，观测维数 `m=3`；观测算子由种子 `20261109` 生成的正交行构成。
- 每个坐标使用稀疏高斯混合先验：`z_i ~ Bernoulli(0.18)`；`z_i=0` 时标准差 `0.05`，`z_i=1` 时标准差 `1.0`。共枚举 `2^6=64` 个高斯成分。
- 观测模型为 `y=A x + ε`，`ε ~ N(0, 0.35² I)`。
- 对每个成分解析计算后验高斯参数及混合权重；不使用近似采样器构造参考后验。
- 生成 1,024 个独立 `(x,y)` 联合案例。每个 `x` 在条件于 `y` 时服从上述精确后验。

## 3. 预测分布对照

对每个 `y`，以精确后验混合 `p(x|y)` 为校准分布。使用后验总体均值 `μ`、成分均值 `m_c` 与协方差 `Σ_c` 构造：

```text
q_α(x|y) = Σ_c w_c N(x | μ + α(m_c - μ), α² Σ_c)
```

固定条件为：精确后验 `α=1`、欠分散 `α=0.5`、过分散 `α=1.5`、均值塌缩点预测 `α=0`。预测只依赖 `y` 和预设模型，不使用目标 `x`。

## 4. 指标、区间与预声明判据

1. **主要指标：** 用高斯混合闭式公式计算逐维 CRPS，再对六维取平均；不使用有限预测 draw 的蒙特卡洛近似。
2. **校准量：** 逐维计算 50% 与 90% 等尾可信区间覆盖率。每个案例先对六个坐标的覆盖指示取平均，再对 1,024 个案例等权平均。混合 CDF 使用正态 CDF 数值近似，并用二分法求分位数。点质量均值预测的区间覆盖率照实报告。
3. **不确定性区间：** 以独立案例为单位配对重采样 2,000 次，报告三种非校准条件相对 `α=1` 的 `CRPS_候选−CRPS_精确` 百分位 95% bootstrap 区间。
4. **通过描述性判据：** 三种非校准条件的平均 CRPS 差 95% 区间下界均大于零；精确后验的 50% 与 90% 经验覆盖率分别距标称值不超过 `0.04`。
5. 所有覆盖率与方向性结果均报告；未达判据时原样记录，不调参、不改指标定义。

## 6. 解释边界与停止规则

通过只说明这些评分在指定的六维稀疏高斯混合、线性高斯观测案例中识别了预设的分布失配。它不验证 SAR 表示域、空间图像场、真实模型 draw、项目观测似然或物理后验校准；不修改 C3-A v3、任何 gate、模型代码或训练状态。数值不稳定或判据未通过时，保留失败证据并停止，不据此调整模型或 gate。
