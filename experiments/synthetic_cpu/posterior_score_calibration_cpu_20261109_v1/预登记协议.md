# 已知稀疏混合后验下的分布评分校准诊断

**状态：** 已预登记，待运行。
**日期：** 2026-11-09。
**类型：** 纯合成、NumPy CPU 方法诊断；不含训练或项目图像。

## 1. 研究问题

检验逐维 CRPS 与边际可信区间覆盖率，能否在一个可精确求解的小型逆问题中，把来自真实后验的预测分布与后验均值塌缩、欠分散和过分散的预测分布区分开。该问题补充现有的评分公式、空间依赖和亮点合成诊断；它不评价 SAR 模型或 C3-A v3。

## 2. 已知后验构造

- 目标维数 `d=6`，观测维数 `m=3`；固定线性观测矩阵由随机种子 `20261109` 产生的正交行构成。
- 每个目标坐标使用稀疏高斯混合先验：隐变量 `z_i ~ Bernoulli(0.18)`；`z_i=0` 时标准差为 `0.05`，`z_i=1` 时标准差为 `1.0`。六维共有 64 个高斯混合成分。
- 观测为 `y=A x + ε`，其中 `ε ~ N(0, 0.35² I)`。
- 枚举全部隐变量组合；每个组合的后验条件分布为高斯，其精确混合权重由观测似然计算。该构造避免用近似采样器生成“参考后验”。
- 从先验与观测的联合分布生成 1,024 个独立 `(x,y)` 案例。每个 `x` 是对应 `y` 下真实后验的一个条件样本。

## 3. 预测分布对照

对每个 `y`，使用精确后验混合 `p(x|y)` 作为校准分布。以其后验总体均值 `μ` 和每个高斯成分均值 `m_c` 构造：

```text
q_α(x|y) = Σ_c w_c N(x | μ + α(m_c - μ), α² Σ_c)
```

固定四种条件：精确后验 `α=1`、欠分散 `α=0.5`、过分散 `α=1.5`、均值塌缩点预测 `α=0`。分布条件仅由 `y` 与预设模型确定，不使用观测目标 `x`。

## 4. 评价量与预声明判据

1. **主要指标：** 对每个坐标按高斯混合闭式公式计算 CRPS，再在六维内求均值。该计算不依赖有限 draw 的蒙特卡洛近似。
2. **校准量：** 对每个坐标计算 50% 与 90% 等尾后验区间的覆盖率。混合 CDF 使用正态 CDF 数值近似，并以二分法求分位数。
3. **配对不确定性：** 对案例重采样 2,000 次，报告每个非校准条件相对 `α=1` 的 CRPS 差 `CRPS_候选−CRPS_精确` 的百分位 95% bootstrap 区间。重采样单位是独立合成案例。
4. **通过描述性判据：** 三种非校准条件各自的平均 CRPS 差 95% 区间下界均大于零；`α=1` 的 50% 与 90% 经验覆盖率分别落在目标值 ±0.04 内。
5. 覆盖率及欠/过分散方向均完整报告；不把它们转化为 C3-A 门槛。未达预声明判据时记录为未通过，不调参、不改评分定义。

## 5. 随机性、运行与产物

- 数据、后验样本、bootstrap 分别使用由固定主种子派生的独立 NumPy 随机数流；主种子为 `20261109`。
- 运行使用 Python 与 NumPy，不导入 PyTorch，不访问 GPU、项目图像、数据清单、模型、checkpoint、confirmation 或 test。
- 只保存每案例的汇总分数与覆盖指示，以及小型 JSON 汇总和命令记录；不保存大张量。
- 运行前复核项目分区可用空间。输出限定于本唯一新目录，禁止覆盖已有实验。

## 6. 解释边界与停止规则

即使通过，结果也只说明这些评分在指定的六维稀疏高斯混合和线性高斯观测案例中能识别预设的过/欠分散。它不验证 SAR 表示域、空间图像场、真实模型 draw、数据一致性似然或物理后验校准。该诊断不修改冻结 C3-A v3、任何 gate、模型代码或训练状态。若数值稳定性或通过判据失败，则保存失败证据并停止本诊断，不根据结果改变模型或 gate。

## 7. 依据

Zach、Haouchat 与 Unser 的 ICLR 2026 论文 *A Statistical Benchmark for Diffusion-Posterior-Sampling Algorithms* 使用可精确采样的离散 Lévy 过程后验作金标准，并提出后验覆盖与最优性差距检查。本文只借鉴“与可知后验直接比较”的验证思想；本协议不是该论文基准的复现，先验、观测维数和评分范围均不同。正式来源及适用边界见同目录[文献审查记录](../../literature_audits/posterior_sampling_statistical_benchmark_20261109_v1/报告.md)。
