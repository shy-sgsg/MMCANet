# 已知双峰分布下的评价样本数敏感性诊断

## 研究问题与方法

本实验测量评价集合大小对分布比较稳定性的影响。使用预登记的二维等权双峰高斯目标，比较正确双峰抽样与两种错误分布：匹配目标总体均值和协方差的单峰高斯、模态权重为 0.8/0.2 的偏置双峰。评价集合大小为 4、8、16、32、64、128、256；每个大小进行 100 次重复，每次用 2,048 个独立目标样本计算能量分数。

主要量是同一重复内“错误候选能量分数 − 正确双峰抽样能量分数”。正值表示正确样本集合得分更低。报告配对差均值、重复间标准差，以及 100 次重复中正确双峰抽样分数较低的比例。不同评价集合大小使用同一组嵌套候选样本，减少跨样本数对照的随机差异。

## 结果

| 候选错误分布 | 集合大小 | 配对能量分数差（均值 ± 标准差） | 正确抽样分数较低的重复比例 |
|---|---:|---:|---:|
| 矩匹配单峰高斯 | 4 | 0.1606 ± 0.5115 | 0.66 |
| 矩匹配单峰高斯 | 8 | 0.1178 ± 0.2600 | 0.78 |
| 矩匹配单峰高斯 | 16 | 0.1102 ± 0.1533 | 0.86 |
| 矩匹配单峰高斯 | 32 | 0.1226 ± 0.0693 | 0.95 |
| 矩匹配单峰高斯 | 64 | 0.1248 ± 0.0511 | 0.98 |
| 矩匹配单峰高斯 | 128 | 0.1285 ± 0.0325 | 0.99 |
| 矩匹配单峰高斯 | 256 | 0.1305 ± 0.0181 | 1.00 |
| 0.8/0.2 偏置双峰 | 4 | 0.2692 ± 0.6663 | 0.63 |
| 0.8/0.2 偏置双峰 | 8 | 0.3320 ± 0.4419 | 0.81 |
| 0.8/0.2 偏置双峰 | 16 | 0.3761 ± 0.3309 | 0.90 |
| 0.8/0.2 偏置双峰 | 32 | 0.4407 ± 0.2239 | 0.99 |
| 0.8/0.2 偏置双峰 | 64 | 0.4428 ± 0.1577 | 1.00 |
| 0.8/0.2 偏置双峰 | 128 | 0.4365 ± 0.1148 | 1.00 |
| 0.8/0.2 偏置双峰 | 256 | 0.4470 ± 0.0853 | 1.00 |

按预登记的 0.90 重复比例描述阈值，矩匹配单峰高斯在集合大小 32 首次达到该比例，偏置双峰在 16 首次达到。单峰高斯的配对差第 10 百分位在 32 时转为正值；偏置双峰在 16 时仍约为 −0.0008，至 32 才明显为正。集合大小增加时，两类错误候选的分数差重复间波动总体下降。

## 结论边界

在该二维已知分布中，小集合的单次分数比较容易受抽样波动影响；更大的集合改善了两种错误分布与正确抽样之间的区分稳定性。集合大小 16 或 32 只是在本设定下跨过预登记描述阈值的观察，不是对真实 Flow/Diffusion 的推荐 draw 数，也不是统计功效保证、校准结论或阶段门槛。真实输出的维数、样本相关性、指标域和运行成本均未在这里建模。

本实验只使用 NumPy 合成随机数；未读取项目影像、模型、checkpoint、confirmation/test 载荷或测试测量值；未训练、未使用 GPU，不改变 C3-A v3、任何阶段 gate 或训练状态。
