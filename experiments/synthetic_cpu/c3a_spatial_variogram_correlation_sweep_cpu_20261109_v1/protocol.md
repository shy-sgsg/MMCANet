# 多尺度变差分数相关强度敏感性协议

- **版本：** `c3a_spatial_variogram_correlation_sweep_cpu_20261109_v1`
- **状态：** 预登记后运行；这是上一项 ρ=0.8 诊断的敏感性延伸，不是独立 SAR 复制。
- **运行日期：** 2026-11-09
- **设备：** NumPy CPU；不导入 PyTorch。

## 问题与动机

上一项预登记诊断只比较一阶相关 ρ=0.8 的一个 AR(1)/RBF 协方差对。检查多距离变差分数在较弱和较强一阶相关下是否仍能识别两族远距离相关差异，避免把单一参数点的结果直接提升为一般设计建议。

## 固定协议

- 图像：`24×24` 可分离高斯场，经 sigmoid 映射到 `[0,1]`。
- 家族：AR(1) 协方差 `ρ^|i-j|`；RBF 协方差 `exp(-(i-j)^2/(2ℓ^2))`，其中 `ℓ=sqrt(-0.5/log(ρ))`，使两者一阶相关完全匹配。
- 一阶相关：`ρ∈{0.4,0.6,0.8,0.9}`。
- 真值方向：每个 ρ 分别以 AR(1) 与 RBF 为真值。
- 每个 `(ρ, 真值族)` 条件 300 个独立目标；每个目标 16 个预测 draw。预测家族之间使用同一个重复的高斯底噪，形成配对比较。
- 评分：逐像素 CRPS、按 `sqrt(P)` 归一化的整图能量分数、`h=1,2,4,8` 的 `p=1` 单尺度变差分数，以及四个尺度等权平均。公式沿用[首项协议](../c3a_spatial_variogram_multiscale_cpu_20261109_v1/protocol.md)，本实验不改定义。
- 生成 seed：`20261110`；percentile bootstrap seed：`20261111`，每条件 2,000 次，重抽样单位为独立目标。

## 预先声明的判定

- 对每个 `(ρ, 真值族)` 条件，只有多尺度变差分数的平均配对差 95% bootstrap 区间下界大于零，且正确模型逐重复排序比例大于 `0.65`，才记录该条件达到预登记描述门槛。
- 单尺度 `h=1` 的排序比例按匹配二像素分布的理论预期检查是否落于 `0.40–0.60`；不满足时排查有限样本/实现配对，不调整公式。
- 所有条件一并报告；不因结果挑选 ρ、距离或权重。无论通过与否均不更改 C3-A v3、正式协议、模型设置、阶段 gate 或 draw 数。

## 数据与设备边界

仅生成合成矩阵。不得读取项目影像、模型、checkpoint、confirmation/test 载荷或测试测量值。无训练、推理、PyTorch 或 GPU。结果仅描述该高斯 copula、两种协方差族、24×24 尺寸与 K=16，不证明其他 SAR 结构或生成模型校准。
