# 流模型逆问题控制与后验采样统计基准文献审查

**审查日期：** 2026-11-09。
**范围：** 补查流模型逆问题求解与可检验后验样本评价两类一手来源。
**数据边界：** 未访问项目图像、分割清单、模型、checkpoint、confirmation 或 test；无训练、推理或 GPU。

## 一、ICML 2026 MPC-Flow：训练后推理控制的新增先例

Webber、Denker、Barbano 与 Reader 的 *Solving Inverse Problems with Flow-based Models via Model Predictive Control* 收录于 ICML 2026、PMLR 第 306 卷。PMLR 官方页面摘要称，MPC-Flow 将基于流模型的逆问题条件生成写成一系列模型预测控制子问题，用于生成时的最优控制引导；作者报告了一组可避免穿过整个生成轨迹反传的算法选择，并在图像修复、去模糊及超分辨率任务上评估，包含对量化 FLUX.2 的训练后引导。

本次能读取 PMLR 官方书目和摘要，但其 PDF 下载端点未被当前读取工具支持；因此不推断论文正文里的损失权重、观测噪声、数据划分、运行成本、具体基线或数值效果。记录级别为出版方摘要，不是全文方法审查。

**对本项目的影响：** 训练后 Flow 先验的观测引导、逆问题超分控制已是通用方法先例。它缩小“把 Flow 先验用于逆问题并在推理时注入条件”这一宽泛新颖性空间，但不涉及 SAR 输出、SAR 斑点、光学条件、SAR 联合去斑与超分，也不验证本地表示域似然。若未来研究此方向，只能在生成先验和观测模型分别具备资格后，将 MPC 类求解器作为 C4/C6 候选，与直接条件生成和确定性基线比较；本次不实现、不解锁该路线。

## 二、ICLR 2026 统计基准：精确后验用于分布级验证

Zach、Haouchat 与 Unser 的 *A Statistical Benchmark for Diffusion-Posterior-Sampling Algorithms* 是 ICLR 2026 正式论文。OpenReview 托管的会议全文说明：作者使用具有可行 Gibbs 精确条件分布的离散 Lévy 过程，获得金标准后验样本；以 MMSE 最优性差距和最高后验密度区域覆盖检查扩散后验采样，并涵盖去噪、反卷积、缺失值插补和部分 Fourier 重建。论文还讨论以匹配的后验样本进行分布层比较，并公开基准代码。

该工作说明，只看单个点估计或图像质量指标不足以验证后验采样；当存在可控的精确真值时，应直接检查后验覆盖和分布对象。其观测设定是线性逆问题，不能直接说明 SAR 斑点、归一化 PNG 似然、光学引导或本地模型的校准程度。

## 三、本地非 GPU 方法诊断

基于“与已知后验直接比较”的方法启发，完成了独立的六维稀疏高斯混合线性逆问题 CPU 诊断，目录为 [v1r1 运行记录](../../synthetic_cpu/posterior_score_calibration_cpu_20261109_v1r1/报告.md)。它解析枚举 64 个混合成分，用闭式混合 CRPS 与边际区间覆盖检查精确后验、欠/过分散预测及后验均值塌缩。1,024 个联合案例中，三种错误预测相对精确后验的 CRPS 差 95% 配对 bootstrap 区间下界均大于零；精确后验的 50%/90% 区间覆盖为 0.4990/0.9014，均达到预登记判据。

首轮实现误用五维而非预登记的六维目标。维度断言按预期失败；首轮 CSV/汇总保留在原目录并标记无效。随后用唯一新目录完成符合原参数和判据的 v1r1 复跑，没有覆盖首轮产物，也没有按首轮结果调参。

## 四、研究决策与限制

- 采用 ICLR 论文的已知后验比较原则，作为候选评价设计的支持依据；本地六维合成诊断只证明所指定混合分布和线性高斯观测下的计算行为。
- 不将其称作 SAR 后验校准，不用于 C2/C3 晋级，不修改 C3-A v3、任何阶段 gate、训练状态或数据权限。
- MPC-Flow 仍是出版方摘要级先例；在取得并审阅全文前，不写入细粒度方法或数值结论。
- 下一步仅在训练恢复且相应先验/观测模型满足门槛后，才重新讨论真实模型分布评价或 Flow 后验推理；本轮保持无 GPU。
