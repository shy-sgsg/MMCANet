## 2. README 明示的技术结构

以下均为作者 README 的描述，不代表本次审查已验证相应实现：

1. **两阶段流程。** 第一阶段 S1 估计光学引导的后验均值；第二阶段 S2 从受扰动的 S1 估计开始，使用条件速度网络和 Euler 积分进行生成式重建。
2. **S1 组件。** README 列出 SAR token encoder、光学编码器、TDA、CSM、重建路径和 HDB 等组件，并称 RGF 用于引导融合。
3. **S2 条件。** README 描述上采样 SAR 与光学条件共同输入速度网络。
4. **可靠性门控融合（RGF）。** README 称其使用由引导预测的分组核过滤 SAR 特征，并以学习得到的信任图调节中心偏置和光学注入；该模块在 S1 与 S2 中均使用。
5. **公开评测说明。** README 列出 ×4、×8、×16 设置及多个数据集／评测配置，并提及 EMA、边界裁剪、重叠分块推理等做法。本次未检查这些配置、数据或结果。
