# AllClear train/validation 样本可执行性筛查（2026-11-28）

## 结论

本次交叉筛查把“地理角色表中的 ROI”与“已发布任务 JSON 中可实际迭代的样本”分开核对。官方显式 train/validation 清单分别有 19,013/997 个 ROI，互斥；五份 train/validation 样本 JSON 的 ROI 均落在各自显式清单内。共享 `rois_metadata.csv` 多出的 34 个 train 角色 ROI 不在任何已检查的 train JSON 中；显式清单另有 334 个 train ROI 和 13 个 validation ROI 没有出现在本归档检查的任何相应 JSON 中。

因此，后续如继续审 AllClear，只能把显式角色清单与相应任务 JSON 的交集当作可执行候选队列。该结果不说明 34 个额外 ROI 或 347 个未覆盖 ROI 的逐项剔除原因；也不改变 AllClear 原任务是 S2 云去除、S1 辅助且没有 clean SAR target 的事实。它目前仍不满足 SAR 联合去斑/超分实验的数据资格。

## 解释边界与后续

作者数据构建代码会依据任务条件形成可训练序列；但仅凭聚合覆盖差异无法判定某个 ROI 缺失的具体原因。额外 34 行与旧版/合并元数据计数差异的对应关系只是线索，不能写成已证实的逐项剔除历史。中心点距离也不能代替完整影像 footprint、栅格配准、地表稳定性或 SAR 目标质量审计。

下一步寻找不同于既有 Task B 来源的 SAR 输出数据。AllClear 的本地身份交叉、目标域和配准仍未核验，且任务方向不匹配；不下载其全量载荷。Mendeley 全球 Sentinel-1 多时相参考已用于 Task B 的 GT25 表示域代理，单景 SAR 包因缺直接配对键而排除，不能当作新的独立来源。后续路线及边界见[广域来源路线复核](../../../docs/research/PHASE_E_BROAD_SAR_DATA_ROUTE_REVIEW_20261128.md)。
